## 图谱 API 与上限

| API | 契约 |
|---|---|
| `GET /api/v1/graph?q=&kind=nodes|edges&limit=50` | 最多 100 节点和 300 条关系；名称/关系描述、关键词或端点名称匹配；仅返回选中节点之间的关系；总量和截断标记明确 |
| `GET /api/v1/graph?nodeId=<id>&limit=50` | 从选中节点展开一层邻居，保留相同上限；已删除节点返回 404 |
| `GET /api/v1/graph/sources?kind=node|edge&id=<id>&offset=0&limit=10` | 每页最多 20 个真实文本块及文档名称/版本/原始位置；不发送完整配置或密钥 |
| `GET /api/v1/documents?q=&status=&offset=0&limit=10` | 名称忽略大小写，状态精确过滤；过滤后计算总量和分页 |

图谱主响应只带来源数量，不展开全部 sourceChunkIds；来源另行分页读取。每次图谱/来源请求捕获一个稳定 SnapshotView，不调用模型。来源响应的 corpusRevision 与当前图谱不同时要求刷新，避免把新来源误配到旧图谱。仍使用全量内存图，搜索会遍历本地图；没有引入外部数据库或后台图谱服务。

## 渲染、安全与上游适配

`SafeMarkdown.tsx` 选择性适配固定上游 `lightrag_webui/src/components/customization/CustomizedMarkdown.tsx` 的 ReactMarkdown/skipHtml 和链接 rel 处理，保留 MIT 来源。目标端不开放原始 HTML，不执行文档/模型脚本；危险协议链接退为文字，所有图片退为描述，避免自动网络请求。图谱标签、属性、文档名和来源正文使用 React 文本节点。

本阶段采用有数量上限的 SVG 环形布局与可键盘操作的实体/关系列表，替代原计划 Graphology/Sigma 展示依赖；不复制上游完整 store、搜索索引、图编辑或环境变量配置。支持搜索、限量子图、邻居、属性和来源，未提供拖拽、力导布局、缩放或大图浏览。无手工图谱修改入口。新增运行依赖 `react-markdown@10.1.0`（MIT）及 lockfile 中的传递依赖，分发时继续保留各包许可。
